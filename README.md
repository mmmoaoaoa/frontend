# Листок — магазин комнатных растений

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина комнатных растений и товаров для ухода за ними. Работа выполнена по дисциплине «Фронтенд и бэкенд разработка» без CSS-фреймворков.

## Страницы

| Файл | Назначение |
| --- | --- |
| `index.html` | главная: hero-блок, категории, преимущества, популярные растения, отзывы |
| `catalog.html` | каталог: разделы «Растения» и «Кашпо и грунт», карточки, блок фильтров |
| `product.html` | страница товара: изображение, описание, цена, таблица характеристик, кнопки заявки |
| `order.html` | форма оформления заявки и таблица условий доставки |
| `contacts.html` | адрес, телефон, почта, форма обратной связи |
| `care.html` | дополнительная страница: сравнительная таблица ухода, шаги пересадки, вопросы и ответы |

Остальные файлы `product-*.html` — страницы других товаров, сделанные по образцу `product.html`.

## Используемые технологии

- HTML5, семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `figure`, `details`, `table`
- CSS3 во внешнем файле `css/style.css`: переменные в `:root`, Flexbox, CSS Grid, состояния `:hover`, `:focus-visible`, `:disabled`, `:user-invalid`, `:target`
- БЭМ: блоки `page-header`, `main-nav`, `product-card`, `order-form`, элементы вида `product-card__title`, модификаторы вида `product-card--sold-out`, `button--outline`
- Позиционирование: `sticky` у шапки и фильтра каталога, `relative` и `absolute` у карточек и бейджей, `fixed` у модального окна, кнопки «Наверх» и сообщения об отправке, `z-index` для слоёв
- JavaScript в `js/main.js` используется минимально: показывает сообщение после отправки формы и закрывает модальное окно

## Как посмотреть проект

Перейти по ссылке GitHub Pages или скачать репозиторий и открыть `index.html` в браузере. Установка и сборка не нужны.

## Самостоятельные доработки

- Своя тема и оформление: магазин растений, тёмная шапка, зелёно-жёлтая палитра, собственные SVG-иллюстрации
- Модальное окно «Быстрый заказ» на чистом CSS через псевдокласс `:target`: открывается по якорной ссылке, закрывается крестиком, кнопкой «Отмена» и щелчком по затемнению
- Дополнительные страницы: пять страниц товаров и страница `care.html` со сравнительной таблицей, шагами пересадки и блоком вопросов на `details`
- Карточки товаров: бейджи «Хит», «Новинка», «Скидка», список условий ухода, старая цена, статус наличия, вариант карточки для отсутствующего товара
- Навигация: хлебные крошки, якорное меню разделов в каталоге и на странице ухода, плитки категорий на главной, быстрые ссылки в подвале, фиксированная кнопка «Наверх»
- Формы: дата доставки, способ получения, подарочная упаковка, подсветка неверно заполненных полей, всплывающее сообщение об отправке
- Блок отзывов и призыв к быстрому заказу на главной
- Доступность: заметный фокус у ссылок, кнопок и полей, `label` у каждого поля, подписи навигаций через `aria-label`, скрытый заголовок для раздела категорий, учёт `prefers-reduced-motion`
- Базовый медиазапрос, перестраивающий сетки в одну колонку на узком экране
