# Листок — магазин комнатных растений

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Учебный многостраничный HTML/CSS-сайт интернет-магазина комнатных растений и товаров для ухода за ними. Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

## Технологии

- HTML5
- CSS3

## Как посмотреть проект

Открыть файл `index.html` в браузере.
